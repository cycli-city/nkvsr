# Code of Conduct

This project follows the spirit of the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/):
a harassment-free, welcoming space for everyone who takes part, whatever their background or experience.

**Expected:** be respectful and constructive; give specific, kind feedback; accept feedback gracefully; focus on what is best for the project
and its users; assume good faith.

**Not acceptable:** harassment, insults or personal attacks; discriminatory language or imagery; publishing someone's private information;
trolling or sustained disruption; anything else that would be inappropriate in a professional setting.

**Enforcement:** the maintainer may edit or remove comments, issues, pull requests and commits that violate this code, and may restrict
participation. To report a problem, use a [private security advisory](https://github.com/cycli-city/nkvsr/security/advisories/new)
(it reaches the maintainer only) or contact the maintainer through their GitHub profile.

This code applies in all project spaces: the repository, its issues and pull requests, and any place where someone represents the project.
